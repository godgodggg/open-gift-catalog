# Открытый каталог идей подарков

Бесплатная open-source база и интерактивный поисковик идей подарков. Пользователь выбирает получателя, возраст, повод, интересы, формат и тип подарка, после чего идеи сортируются по релевантности.

## Возможности

- 446 идей подарков;
- множественный выбор категорий;
- приоритет совпадений по интересам;
- сортировка остальных идей по общему числу совпадений;
- полностью статический сайт без сборки и сервера.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне проекта.

## Размещение на Vercel

Импортируйте GitHub-репозиторий в Vercel как проект без фреймворка. После подключения новые изменения из основной ветки будут публиковаться автоматически.
