# Attune: desktop-прототип первой ветки

## Объём

Первый экран использует исходное изображение как фон, а заголовок, служебный текст и CTA накладываются HTML/CSS. Кнопка плавно переводит пользователя к полноэкранной белой секции подбора.

В прототипе реализована одна ветка: «Для неё → 18–25 лет → День рождения → Музыка → Физический подарок → Декор». Результат — трек-пластина с любимой песней. Это позволяет проверить внешний вид и механику до наполнения полного каталога.

Маршрут показан в левой колонке как простой вертикальный степпер: белый фон, тонкая серая линия, чёрная текущая точка и серые будущие шаги. Пройденные шаги работают как навигация: пользователь может вернуться к выбранной категории, после чего этот и все последующие ответы очищаются. Вопрос остаётся главным элементом экрана, но имеет более спокойный размер; вся интерфейсная типографика использует насыщенные начертания.

## Ограничения текущей версии

- Только десктопная компоновка.
- Нет бюджета, оценки практичности или эмоциональности.
- Нет ссылок на магазины и паблики.
- Остальные получатели, поводы, интересы и типы будут добавлены после проверки прототипа.

Первой кнопкой на каждом шаге служит нейтральный вариант «Без разницы». Он позволяет продолжить подбор без ограничения по соответствующей категории. Пользователь может выбрать несколько конкретных вариантов, после чего перейти к следующему шагу отдельной кнопкой «Далее».

Финальный экран показывает список идей из исходного каталога. Для каждой идеи вычисляется число совпавших выбранных значений; карточки сортируются по убыванию этого числа.
